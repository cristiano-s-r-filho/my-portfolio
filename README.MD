## Getting Started

To explore the projects within this portfolio:

1.  Clone the repository:
    ```bash
    git clone https://github.com/cristiano-s-r-filho/my-portfolio.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd my-portfolio
    ```
3.  Follow the specific instructions within each project's subdirectory for setup and execution.
